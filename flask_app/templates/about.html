About the Application

This web application helps users understand and estimate delays in public transportation systems such as buses, metro trains, and railways.

By entering a source and destination, the system predicts possible delays and travel time using traffic conditions, weather data, and distance.

The application also stores user travel history and displays insights through a dashboard for better analysis and understanding.

System Highlights

• User login and authentication
• Delay prediction for public transport
• Recent trip history
• Dashboard with travel insights
• Simple and user-friendly interface

Technology Stack

Python Flask SQLite Machine Learning HTML CSS JavaScript

This application is developed as part of an academic project to demonstrate real-time data handling and predictive analysis in web applications.

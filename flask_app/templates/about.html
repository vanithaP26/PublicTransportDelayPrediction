About This Project

The Public Transport Delay Prediction System is a simple and intuitive platform designed to estimate delays for **Bus, Metro, and Train** based on weather, traffic conditions, and historical patterns. It helps users plan better by providing route insights, delay estimates, and an interactive dashboard for recent searches.

This project is built as a demonstration for academic purposes, focusing on user-friendly design, clean data pipelines, and practical machine-learning integration.

Technologies Used

Python Flask SQLite Pandas NumPy scikit-learn Chart.js Leaflet Maps HTML / CSS

Purpose

The goal is to provide a simple, easy-to-understand system that shows how real-time data, geocoding, weather APIs, and predictive modelling come together in a full working application.

For demo or educational use only.
